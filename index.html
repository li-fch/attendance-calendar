跨设备云端同步 (iPhone / MacBook / PC)

通过 GitHub Gist 私有云存储同步涂色记录、请假天数与出勤率配置，多端只需填入同一个 Token 即可互通。

三步开启 iPhone / MacBook / PC 实时同步：

  1. 登录 GitHub，访问 Settings → Developer settings → Personal access tokens → Tokens (classic)，点击 Generate new token。
  2. 勾选 gist 权限后生成，复制生成的 ghp_... 令牌粘贴到下方 GitHub Token 输入框（留空 Gist ID 首次上传会自动创建私有 Gist）。
  3. 在另外两台设备（如 iPhone 或 MacBook）打开本页面，填入相同的 Token（及自动生成的 Gist ID），点击“从云端拉取”即可同步全部数据。
